# E-Commerce Sales Analysis

## 📌 Project Overview
This project analyzes e-commerce sales data using Excel, MySQL, Python, and Power BI. The goal is to understand sales performance, profitability, customer behavior, product performance, and regional trends.

## 🛠️ Tools Used
- **Excel:** Data cleaning, PivotTables, charts, and dashboard creation
- **MySQL:** SQL queries, aggregations, joins, subqueries, and business analysis
- **Python:** Data analysis using Pandas and data visualization using Matplotlib
- **Power BI:** Interactive dashboard with KPI cards, charts, and slicers
- **GitHub:** Project documentation and version storage

## 📊 Key Performance Indicators
- **Total Sales:** ₹9,248,905
- **Total Profit:** ₹1,302,212.25
- **Total Orders:** 500
- **Total Quantity Sold:** 961
- **Average Order Value:** ₹18,497.81

## 🔍 Analysis Performed
- Sales and profit analysis by category
- Regional sales comparison
- Monthly sales trends
- Top-selling products and customers
- Profit margin analysis
- Discount and profit relationship analysis
- Target achievement and sales gap analysis
- Data quality checks for missing values, duplicates, and invalid values

## 📁 Project Files
- `Ecommerce_Sales_Analysis.ipynb` — Python analysis notebook
- `Ecommerce_Sales_Analysis.pbix` — Power BI dashboard
- `Ecommerce_Sales_dataset.csv.xlsx` — Source workbook
- `ecommerce_sales_analysis.sql` — SQL analysis queries
- - `category_summary.csv` — Category-wise sales, profit, and profit margin summary
- `ecommerce_sales_cleaned.csv` — Cleaned dataset
- `kpi_summary.csv` — Overall KPI summary
- `monthly_sales_summary.csv` — Monthly sales summary
- `top5_products.csv` — Top 5 products summary

## 💡 Key Findings
- Electronics generated the highest sales among the categories.
- The Central region recorded the highest regional sales.
- August recorded the highest monthly sales.
- Laptop was the highest-selling product.
- Electronics generated the highest total profit.

This project demonstrates an end-to-end data analytics workflow, from data preparation and SQL querying to Python analysis, dashboard development, and business insight generation.
